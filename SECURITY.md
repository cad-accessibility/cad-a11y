# Security

## Reporting a vulnerability

Please don't report a security problem in a public issue, discussion or pull request. That shows it
to everyone before it can be fixed. Use one of these private routes instead:

- **On GitHub:** on the repository's Security tab, choose "Report a vulnerability", or open
  https://github.com/cad-accessibility/cad-a11y/security/advisories/new. Only you and the project's
  maintainers can see the report.
- **By email**, if you don't have a GitHub account or would rather write: send it to
  ctejada at cs dot washington dot edu, typing "@" for "at" and "." for "dot", with a subject that
  starts with "Security". Carlos Tejada reads it. The address is written out so that spam crawlers
  can't collect it.

## What to include

- What the problem is and where: a page, an address on the site, or a file in this repository.
- The steps that make it happen.
- What someone could do with it.

Please don't look at, change or delete anyone else's models or data beyond what you need to show the
problem.

## What happens next

You'll get a reply once someone has looked at the report. We'll agree with you when to make it
public, after the fix is deployed.

## What this covers

The code on the `master` branch.
