                Keyboard Commands

                Press Esc or activate Close to return to where you were.

                • C Show the current step: script, prompts, and status
                • S Show strategy prompts
                • J Jump to a step
                • N Next step
                • B or P Back to the previous step
                • R Run the study on this device — hands this window to the participant; use if you have only one computer
                • E End session
                • H or ? Open this help
                • Esc Close a dialog
                • N/B/P work even with another dialog open — they replace it with the current step
