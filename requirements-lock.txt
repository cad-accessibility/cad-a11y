# The exact versions pip installs in the Docker image and in CI (#240).
# Linux, Python 3.12.
#
# requirements.txt says what the app depends on; this says which versions it
# gets, so that building the image twice, a week apart, installs the same thing.
# Without it every rebuild re-resolved each package to its newest release, and a
# new geometry library shows up as a subtly different render, not as an error.
#
# The rest of the Python packages come from conda, pinned in environment.yml:
# numpy, matplotlib, pillow and what they bring with them. None of those is
# here, so pip finds them already satisfied and nothing is installed twice.
#
# Taken from the staging deploy of ef0970b on 2026-09-25, which is what staging
# has run since. To change a version, change it here, and in requirements.txt if
# it is a direct dependency, one package at a time, so CI tests that change on
# its own.
