Keyboard Shortcuts

Press Esc or activate Close to return to where you were.

Orientation

  • U Roll counterclockwise (90°): Rotate around forward facing axis
  • O Roll clockwise (90°): Rotate around forward facing axis
  • I Pitch up (90°): rotate around horizontal axis.
  • K Pitch down (90°): rotate around horizontal axis.
  • J Yaw left (90°): rotate around vertical axis.
  • L Yaw right (90°): rotate around vertical axis

Depth & Zoom

  • Arrow Up Shallower 1%
  • Arrow Down Deeper 1%
  • Page Up Deeper 10%
  • Page Down Shallower 10%
  • 5 Zoom in 1%
  • 4 Zoom out 1%
  • 3 Zoom in 10%
  • 2 Zoom out 10%

View & Render Mode

  • R Cycle render mode
  • T Cycle view mode
  • F Fit current slice to tactile display
  • . Read current status

Slice Graph

  • G Refresh slice graph
  • V Toggle slice-graph lock

Position & Pan

  • W Pan object up
  • A Pan object left
  • S Pan object down
  • D Pan object right
  • Z Reset position
  • [ Toggle scrollbar overlay
  • ] Toggle slice-graph overlay

Export

  • P Print current render

About

The CAD accessibility project is an open source effort to improve CAD accessibility for screen reader users. We currently support the Monarch and DotPad displays. To learn more about our project, check out CAD Accessibility.
